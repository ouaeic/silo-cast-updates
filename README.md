# Silo Cast updates

Release files for a personal build of the Silo Android app (casting to older
Chromecasts). The app checks
`releases/latest/download/latest.json` here for updates; each release holds
the APKs and that file.

The source code is kept in a private repository. Silo Android is licensed
under the GNU AGPL v3; the corresponding source for any APK here is available
on request from the repository owner.
